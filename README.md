# vinharia-agnello

#Sobre o projeto: este projeto é um site de uma vinheria, com o objetivo de apresentar produtos e informações. A aplicação permite que o usuário insira informações básicas sobre vinhos e vizualize os dados cadastrados por meio do console do navegador.

##Objetivo:
-Praticar conceitos fundamentais de desenvolvimento web
-Utilizar JavaScript para interação com o usuário 
-Trabalhar organização de arquivos e estrutura de projeto

###Estrutura do projeto 
-HTML
-CSS
-JavaScript

###Funcionalidades
O sistema realiza um cadastro simples de vinhos, solicitando ao usuário as seguintes informações:
-Nome do vinho
-Safra
-Quantidade em estoque
-Valor de custo e venda

####Após a coleta desses dados, as informações são exibidos no navegador


#Forma de execução:
-O usuário insere o nome do vinho, o tipo (tinto,branco ou rosé), a safra, e a quantidade em estoque
Após a coleta dessas informações, os dados são exibidos no console do navegador.

##Lógica aplicada: 
O sistema usa variáveis para armazenar temporariamente os dados fornecidos. Após cada dado inserido, o sistema exibe um aler() confirmando que a informação foi registrada.

###Exibição dos dados 
Depois de coletar todas as informações, o sistema utiliza console.log() para exibir os dados no console de forma organizada.

####Como executar o projeto
1-abra o arquivo do projeto no navegador
2-preencha as informações solicitadas nas janelas que aparecerão
3-ao finalizar, abra o console para visualizar os dados cadastrados
